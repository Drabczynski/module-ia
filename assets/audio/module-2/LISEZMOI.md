> Un bon prompt se construit avec cinq briques : le rôle, la cible, l’objectif, le contexte, et le format. Retournez chaque carte pour découvrir à quoi elle sert.

## 6. Reconnaître les briques

## 7. La brique oubliée

## 8. Construire le prompt
Fichier : `construire.mp3`

> Voici le message de Sophie. À gauche, le prompt est prêt en cinq cases : une par brique. Cliquez sur chaque case orange, choisissez la bonne réponse, ou écrivez la vôtre, puis envoyez.

## 9. Vérifier le résultat
Fichier : `verifier.mp3`

> Un prompt structuré donne un bien meilleur résultat. Mais on vérifie toujours. Comparez l’offre, à gauche, avec le message de Sophie : quelle information manque ?
