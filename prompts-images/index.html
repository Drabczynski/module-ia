Réflexion

Lecture de la demande : un module pour apprendre à demander une image à une IA.

Un résultat décevant vient souvent d’un prompt flou : il manque le sujet, le style, le cadrage ou l’usage.

Choix d’un cas concret pour s’exercer : le post d’une médiathèque qui annonce un atelier.

Plan : un réglage à la fois, puis un prompt complet à écrire et à corriger.

Des prompts
pour les images

Une image générée dépend presque entièrement de la façon dont on la demande. Dans ce module, vous apprenez à régler quatre paramètres : le sujet, le style, le cadrage et l’usage. Vous les appliquez à un cas réel : illustrer le post d’une médiathèque qui annonce un atelier. À la fin, vous saurez écrire un prompt d’image précis, puis l’ajuster à chaque support.
